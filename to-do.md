## Фаза 4. Флоу тестирования (§6)
- [ ] Выборка: `next_review > сегодня`; `ORDER BY last_tested ASC NULLS FIRST,
      next_review DESC`; размер = `test_count`.
- [ ] RU→EN: промпт → ждём ответ → `isCorrect` (детерминизм). Верно → дальше
      (+`last_tested`); неверно → «Не правильно!» + `reset(next_review)` + `last_tested`.
- [ ] Аварийный выход «Показать ответ / Пропустить» = провал.
- [ ] Цикл: гонять неправильные до верного.
- [ ] Режим `test`: коллизия (русский ввод → «только на английском»), таймаут 20 мин. (§8)
- [ ] Фоллбэк-слова тестируются наравне со всеми (принятый риск, known_issues №5).
